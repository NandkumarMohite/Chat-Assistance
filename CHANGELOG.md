# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-12

### Added
- Initial project structure for Ollama Chat AI.
- Express.js backend with modular routing.
- Integration with Ollama Thinking Models.
- Dynamic API registry system via `api-registry.json`.
- Docker support with `Dockerfile`.
- Jenkins CI/CD pipeline configuration (`Jenkinsfile`).
- Health, Chat, Models, and Registry API endpoints.
- Basic frontend in `public/` directory.
